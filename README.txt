КАРАТЕЛИ | СИСТЕМА ПОВЫШЕНИЯ

УСТАНОВКА НА BOTHOST
1. Распакуйте архив.
2. Скопируйте config.example.json в config.json.
3. Заполните ID канала, ролей и все звания в rank_roles. Важно: добавьте ID роли «Стажёр», иначе текущее звание стажёра не определится.
4. В переменных окружения хостинга создайте BOT_TOKEN и вставьте токен Discord-бота. Токен в config.json не нужен.
5. Установите зависимости: pip install -r requirements.txt
6. В Discord Developer Portal включите Server Members Intent.
7. Выдайте боту Manage Roles, Send Messages, Embed Links, Use Application Commands, Read Message History.
8. Поднимите роль бота выше всех ролей званий и роли «Стажёр подразделения».
9. Запустите bot.py и выполните /setup_promotion.

РАБОТА
- Подать рапорт может только пользователь с ролью «Сотрудник семьи».
- Целевой участник также должен иметь роль «Сотрудник семьи».
- Текущее звание определяется по ID ролей из rank_roles, с резервной проверкой названия роли.
- В канале заявок публикуется карточка «НОВЫЙ СПИСОК НА ПОВЫШЕНИЕ».
- Одобрение меняет старое звание на выбранное, а роль «Стажёр подразделения» сохраняет только для званий из trainee_department_until_ranks.
- Отклонение требует причину.
- После решения исходная карточка обновляется статусом «ОДОБРЕНО» или «ОТКЛОНЕНО», указывает проверяющего, кнопки блокируются.
- Заявки хранятся в SQLite (promotions.sqlite3), интерактивные кнопки ожидающих заявок восстанавливаются после перезапуска.


УПОМИНАНИЕ СТАРШЕГО СОСТАВА

При публикации нового рапорта бот упоминает роли, ID которых указаны в senior_role_ids в config.json. Укажите ID роли старшего состава (или несколько ID). Упоминание отправляется только при создании новой заявки; everyone и обычные пользователи не пингуются.
